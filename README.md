# Payroll Software

This repository contains a simple payroll calculator written in Python.

## Usage

1. Prepare a CSV file with employee data. A sample `employees.csv` is provided:

```
name,hours_worked,hourly_rate
Alice,40,20
Bob,35,22
```

2. Run the payroll calculator specifying the CSV file:

```
python3 payroll.py employees.csv
```

The script will output each employee's pay and the total payroll amount.
